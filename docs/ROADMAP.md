# Roadmap

Current intent for `harness-public`:

## Phase 1

- public issue templates
- public examples copied or adapted from stable Harness examples
- boundary docs that explain what is public and what remains private

## Phase 2

- release notes and migration notes
- public configuration compatibility matrix
- curated example catalog by task type

## Phase 3

- clearer public contract for artifacts/configs that external users can rely on
- optional docs site or generated reference pages

## Non-goals Right Now

- mirroring the private Harness core repository
- exposing internal-only prompt assets
- pretending the full runtime is open-sourced when it is not
