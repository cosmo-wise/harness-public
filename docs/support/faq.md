# Frequently Asked Questions

## General

**Q: What is Harness?**
A: Harness is an AI-powered software delivery orchestration platform.

**Q: Is Harness open source?**
A: Harness core CLI is private. Public contracts, examples, and documentation are available in this repository.

**Q: How does Harness differ from other AI coding tools?**
A: Harness focuses on organizational delivery orchestration — planning, execution, evaluation, and evidence capture — not just code generation.

## Technical

**Q: What models does Harness support?**
A: Harness supports Claude (Anthropic), GPT (OpenAI), and custom model endpoints.

**Q: Can I use Harness offline?**
A: Yes, Harness supports air-gapped/offline deployment for enterprise customers.
