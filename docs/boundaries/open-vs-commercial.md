# Open vs Commercial Boundaries

## Open (Public)
- Task execution and orchestration
- Worktree management
- Agent framework (Planner, Generator, Evaluator)
- Prompt assets and templates
- Run state management
- Render audit

## Commercial (Private)
- Organization/Project configuration hierarchy
- Policy engine (governance, approval, budgets)
- Human approval workflow
- Audit trails and compliance exports
- Private deployment modes
- SSO/RBAC integration
- Premium prompt assets and evaluation strategies

## Third-Party
- Trace evidence protocol (open in `trace` repo)
- Course planning contracts (commercial in `course` repo)
- Compass delivery portal (commercial in `compass` repo)
