# Support

Use this repo for:

- bug reports against the public examples or documented behavior
- feature requests about public docs/examples/config surface
- requests for additional public examples

Do not use this repo for:

- private customer incidents with sensitive data
- internal Harness core implementation details that are not part of the public surface
- secrets, tokens, or proprietary repositories

When asking for help, include:

- the example config or task file you used
- the exact command you ran
- the observed result
- the expected result
