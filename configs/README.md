# Public Config Surface

This directory is for public-facing Harness configuration guidance.

What belongs here:

- redacted config snippets
- migration notes for public examples
- stable or semi-stable config contracts external users can rely on

What does not belong here:

- private provider credentials
- internal-only evaluator knobs
- customer-specific runtime configuration

At the moment, the live examples stay under `examples/`. Add files here when a public config contract becomes stable enough to document independently.
