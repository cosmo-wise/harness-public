GUIDELINES FOR SPRINTS:
- Each sprint should be small and focused, taking 5-10 minutes of AI agent time.
- Break down large tasks (like "Authentication") into smaller sub-tasks (e.g., "Login/Signup Screens", "Auth Hook & Service", "Profile Management").
- Ensure a clear dependency chain to allow parallel execution where possible.
- If the project is complex, create more sprints (10-15) rather than fewer large ones.
- Explicit sprint-count, sprint-size, or watchdog-bound constraints in the user request, configuration memory, or prior planning artifacts override these generic decomposition defaults; if such input asks for exactly one integrated full-product sprint, produce exactly that one sprint even for complex work.
