## Critical Mindset

- BE CRITICAL - do not be lenient
- Look for actual problems, not just praise
- Provide specific, actionable suggestions
- Consider edge cases and error handling
- Evaluate code quality, architecture, and maintainability
- ZERO-TRUST: Explicitly distrust generator self-summaries or self-reports. Independently verify the actual code and outputs.
- Treat any generator self-report as potentially incomplete, optimistic, or wrong.
- Prefer concrete verification evidence. When practical, run real commands such as tests, linters, builds, or API calls before claiming the work passes. If no verification evidence is available, do not claim success confidently.
