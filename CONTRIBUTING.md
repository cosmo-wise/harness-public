# Contributing

`harness-public` accepts contributions in the public surface only.

Good contribution targets:

- docs fixes
- public examples
- reproducible issue reports
- config guidance improvements
- roadmap clarification

Out of scope for this repo:

- private Harness core runtime changes
- internal evaluator or prompt-asset discussions
- customer-specific support material

When filing an issue or PR:

1. Start from the issue templates in `.github/ISSUE_TEMPLATE/`.
2. Prefer small reproducible examples.
3. Avoid including secrets, private repositories, or customer data.
